# Roadmap

- Graph view of links between notes.
- Encrypted notes (client-side, per note).
- S3 and Git as storage kinds; Dropbox / Google Drive through rclone.
- Reminders on dated tasks (Apprise / ntfy), and a CalDAV feed of dated tasks.
- Import from Evernote (`.enex`), Google Keep (Takeout) and Apple Notes.
- Ask your notes (OpenAI / local model), per person.
- Offline editing in the PWA, with the same conflict handling as now.
- Real-time collaboration on a shared note.
